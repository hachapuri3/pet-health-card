# Карта здоровья питомца

Приложение для ведения электронной картотеки домашних питомцев: учёт прививок, ветеринарных осмотров и фотографий.

# Функционал

- Добавление записи о питомце (кличка, вид, прививка, дата, ветеринар, фото)
- Просмотр всех записей в таблице
- Редактирование и удаление записей
- Загрузка и отображение фотографии питомца
- Автоматическая установка текущей даты при добавлении
- Хранение данных в локальной базе SQLite

# Что использовалось

- **Python 3** — язык программирования  
- **PyQt5** — графический интерфейс  
- **SQLite** — база данных  
- **Pillow** — обработка изображений  
- **Git** — контроль версий
